# Safety Study

用于本地题库复习、分屏跟随检索和离线练习的 Python 工具。

本工具用于考前复习和本地练习。
## 快速启动

1. 安装 Python 3.10 或以上版本（Windows 安装时勾选 Add Python to PATH，并保留 Tcl/Tk 组件）。
2. 将压缩包解压到一个可写文件夹。请先解压，不要在压缩包预览中运行。
3. 双击 `启动复习.cmd`，默认打开“实时跟随”页，或在此文件夹打开终端执行：

```console
python study.py
```

核心功能只用 Python 标准库，无需 pip 安装依赖、账号或联网。JSON 题库已包含，无需重新导入 Excel。没有 Python 的电脑不能直接运行，这个包不是独立 exe。

### 分屏训练：左边换题，右边跟随显示答案

1. 将本地训练题、练习文档或题库窗口放在主显示器左侧。
2. 打开工具的“实时跟随”页，点击“工具靠右”，将工具放到右侧。
3. 点击“选择左侧题目区域”，拖动框出一道题的题干和全部选项。只需选一次，Esc 可取消框选。
4. 点击“开始跟随”。此后只需在左边正常换题，右边会读取选定区域并自动更新答案、当前选项字母和置信度，无需复制粘贴、手动截图或保存图片。
5. 结束或临时切换到其他内容时，点击“暂停”。关闭工具也会终止读取进程。

实时跟随需要 Windows 10/11 的系统中文 OCR，主显示器上的题目区域必须可见。框选区域保存在当前运行的内存中，重启需重新选择。窗口移动、缩放或题目位置改变后需重新框选；工具自身不能与区域重叠。请只框题干和选项，避开鼠标输入框、滚动动画等持续变化的部分。

程序在本地内存中读取区域画面并识别文字，不保存连续截图，也不访问浏览器页面结构、账号或剪贴板。默认约每 0.4 秒检查一次变化，连续两次画面稳定后才识别；画面不变时跳过重复 OCR。新变化被检测到后会清除旧答案，等待新的匹配结果；空白、识别失败、低分结果或异常中断会明确显示状态。更新速度取决于电脑和区域大小，不能保证固定延迟。

**验证范围：** 已通过本地连续文字流的真实 Windows OCR 测试（单选题切换到判断题、选项乱序、去重和停止），以及变化清除旧答案、空白状态、错误暂停等逻辑测试。开发隔离环境的屏幕读取接口返回“句柄无效”，因此尚未完成实际桌面区域连续读取的端到端验证。请在正常已登录、未锁屏的 Windows 桌面运行；如果仍提示读取错误，请保留错误文字以便排查。文件图片模式不受该屏幕接口限制。

### 截图直接识别并显示答案

1. 将一道本地练习题截图保存为 PNG 或 JPG，尽量只保留题干和完整选项。
2. 启动程序，点击“打开截图并显示答案”，选择图片。
3. 程序在本地完成文字识别和题库匹配，直接显示答案内容、截图当前选项字母、匹配分数与置信度，无需再点检索。

Windows 10/11 优先使用系统的中文 OCR 组件。已安装中文 OCR 组件的 Windows 电脑无需另装 Tesseract；未安装时请按下文配置。可先打开包内 `示例题目截图.png` 验证：答案内容应为“有线鼠标”，截图当前选项应为 **D**。

识别文字会回填输入框，原始识别文字保留在结果末尾。识别有误时可手动修改再点“检索候选答案”。低分结果会明确提示未找到可靠匹配。分数衡量题库文本匹配程度，并非 OCR 准确率或答案正确概率。

## 桌面界面

### 题目检索

粘贴一道题的题干，点击“检索候选答案”。也可导入 UTF-8 `.txt` 文件。每次输入一道题，题干在前、选项在后。建议使用以下格式：

```text
涉密计算机可以使用以下____设备。
A. 无线键盘
B. 有线鼠标
C. 无线鼠标
D. 无线网卡
```

此例题库原答案为 A（有线鼠标），输入选项乱序后的答案应显示 B。标号可使用 A.、A、或 A: 等格式，选项最好每行一个。题目编号、全角字符和常见标点会被规范化；换行不会影响题干匹配。未识别出标号时，内容会作为整段题干检索，此时请整理格式。

结果区只显示匹配度最高的一题，包括原题、原始答案、当前选项映射答案、类别及 Excel 行号。“题库原答案”行使用 18 号黑色粗体，放在选项上方；选项文字使用 12 号黑色粗体，当前输入选项答案使用 14 号黑色粗体。实时跟随、文字检索及图片识别采用相同显示样式。内部仍比较其他候选以计算置信度，减少显示数量不会提高置信度。未输入完整选项时，只返回题库原答案；选项缺失、重复或无法区分时，会明确显示未映射，不能将题库字母直接套用到新顺序。

### 本地练习

在“本地练习 / 错题”页选择随机、顺序或错题重练，再选择题型和类别，点击“下一题”。支持单选、多选、判断，选项每题随机排列。先自己选择，再点“检查答案”，即可查看正确答案内容。多选须全部选对且不多选。判断题将 Y 显示为“正确”，N 显示为“错误”。

每次检查后将练习次数及累计错误次数写入同目录 `practice_history.json`。错题重练包含曾答错的题，后续答对不会自动移除。顺序练习的进度仅在当前运行期间保留，重启从头开始。请在切换练习范围后点“下一题”更新题目。此工具没有计时、竞赛计分或及格分模拟。

如需重置记录，关闭程序后备份并删除 `practice_history.json`。记录采用题目内容生成的标识，题库题干、答案或选项变更后视为新题。请避免同时启动多个窗口，以免记录互相覆盖。

## 本地图片 OCR

文件图片模式支持用户手动选择的一张本地 PNG/JPEG/TIFF/BMP 练习图片。实时跟随模式则只在主动开启后读取选定的屏幕区域。

默认 `auto`：Windows 10/11 首先调用系统中文 OCR；不可用时尝试 Tesseract。图形界面使用相同的自动选择流程。调用系统组件时不修改 PowerShell 执行策略。

若提示缺少 Windows 中文组件，在 Windows 设置的“时间和语言 → 语言和区域”中安装简体中文及其“基本输入 / 光学字符识别”组件。安装阶段可能需要联网，识别过程在本地完成。系统组件可用时，无需 pip 安装 OCR 包。

其他系统或希望改用 Tesseract 时，自行安装 Tesseract OCR，并安装简体中文 `chi_sim` 和英文 `eng` 语言包。将安装目录加入 PATH 后，`tesseract --list-langs` 应能看到这两种语言。命令行可用 `--ocr-engine tesseract` 强制选择，或用 `--tesseract` 提供程序完整路径。

每个 OCR 引擎最多等待 90 秒；自动回退时总等待时间可能更长。图片超过 Windows 引擎最大边长时会按比例缩小。系统 OCR 的文字行按图片坐标排序，并清理中文字符间多余空格和常见题型标题；原始文字保持可见。题干中的“不”、数字和选项标号容易误识别，请重点核对。一次识别一道题，不支持多题图片批量拆分。

## 命令行

在解压后的文件夹执行，Windows 也可将 `python` 换成 `py -3`。

```console
python study.py stats
python study.py search --text "涉密计算机可以使用以下设备"
python study.py search --file example_query.txt
python study.py search --file example_query.txt --json
python study.py search --text "涉密计算机可以使用以下设备" --kind 单选题 --category 国家安全
python study.py search --image practice.png
python study.py search --image practice.png --ocr-engine windows
python study.py search --image practice.png --ocr-engine tesseract
python study.py search --image practice.png --tesseract "C:\Program Files\Tesseract-OCR\tesseract.exe"
python study.py practice --count 20
python study.py practice --count 10 --kind 多选题 --category 国家安全
```

题干至少需要 4 个有效字符，检索时请用完整题干。命令行默认只显示最高匹配的一题，`--top` 可显式选择 1 至 10。`--json` 将候选结果写到标准输出，便于本地处理。文本文件应保存为 UTF-8。终端乱码时，可先设置 `PYTHONIOENCODING=utf-8`。

终端 `practice` 不依赖 Tcl/Tk：随机抽题、随机选项，输入 A 或 AC 等字母后再揭示答案，输入 q 结束。结束时显示本轮正确题数与错题编号；终端模式不持久化练习记录。`--count` 可选 1 至 1000，超过当前范围题数时取全部题，`--seed` 可固定随机种子以复现练习。

### 重新导入题库

可使用原上传 Excel 或相同结构的 `.xlsx`，六列表头必须依次为：序号、题型、类别、题目、选项、答案。选项用 `|` 分隔，多选答案如 `A|C|D`，判断用 Y/N。仅支持 `.xlsx`，不支持旧 `.xls`。

```console
python study.py --bank my_bank.json import "附件1-江苏省第十五届大学生安全知识竞赛题库.xlsx"
python study.py --bank my_bank.json gui
```

自定义题库路径 `--bank` 要写在子命令前。不指定时使用 `bank.json`；导入会覆盖目标 JSON，请先备份。导入遇到无效答案会中止，跳过没有预期表头的工作表时会在报告中列明。JSON 中包含原 Excel 的 SHA-256、统计和重复题干报告，便于追溯来源。标准化会忽略标点，保留文字与数字，原文始终保留。

## 匹配分数与置信度

程序先用字符二元组检索最多 100 个候选，再使用文本序列相似度（65%）和字符二元组集合相似度（35%）排序。数字序列不同或正误/否定关键词不同，各乘以 0.85；提供选项但映射失败时再乘以 0.90。

- 高：首个候选分数至少 93，与第二候选至少相差 8 分，且未触发数字/否定词差异提示。
- 中：其余分数至少 75 的候选。
- 低：低于 75 分，通常需要重新输入或核对原题。

**分数和置信度是启发式检索指标，不是答案正确概率，未用独立 OCR 样本进行统计校准。** 重复题干会保留多个候选，差距不足时不判为高。程序不会根据常识推断答案，也无法保证处理所有同义改写。相同题干但不同选项要逐项核对。

选项按内容一一映射：唯一完全相同的内容优先，否则要求相似度至少 0.88、与第二候选至少差 0.12，且一对一无冲突。重复选项或过近的模糊内容会拒绝映射。题库答案始终同时显示，便于复核。

## 附件阅读与数据核对

- Excel：1000 题，单选 350、多选 300、判断 350，共 11 类。导入后未发现无效答案、缺失题干或规范化后重复题干。
- 5 页 PDF 考试端说明：包含登录、顺序/随机练习、模拟/正式考试、历史记录、错题本等操作。PDF 未给出固定抽题比例、统一考试时长或及格分，本工具没有据此编造这些参数。
- 本工具实现独立的本地学习流程，不对 PDF 中的正式考试平台做页面集成，不操作答题按钮或提交试卷。

## 开发与本地文件

本项目运行时只依赖 Python 标准库。Windows OCR 属于系统组件；Tesseract 为可选外部程序。仓库不包含独立可执行文件。

`.gitignore` 已排除个人练习记录、缓存、临时文件、旧版备份和本地环境配置。完整题库 `bank.json` 随此私有项目保存，原始 Excel/PDF 不重复上传。题库内容保持源文件含义，未对其知识正确性作独立审定。
